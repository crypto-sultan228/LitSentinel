## ✨ Features & Innovations

LitSentinel introduces a multi-layered approach to on-chain security and optimization, offering a robust set of functionalities:

### 1. 🚨 Critical Asset Evacuation (Panic Button)
Our flagship security protocol enables instantaneous sweeping of all native funds to a pre-designated safe address in the event of a wallet compromise. This feature is designed for rapid response and maximum asset protection.

-   **Precision Gas Deduction:** Automatically calculates the exact maximum transferable amount after accounting for gas fees, ensuring a 100% success rate for emergency transfers.
-   **High-Priority Execution: Utilizes a 30% gas buffer to prioritize transactions, ensuring immediate inclusion in the next available block on the LitVM network.

### 2. 📈 Pre-Connection Market Intelligence
LitSentinel provides critical market data and network insights **before** wallet connection, empowering users with informed decision-making.

-   **Live LTC Pricing & Market Cap:** Real-time tracking of Litecoin (LTC) price against USD and its market capitalization, integrated via the CoinGecko API.
-   **Network Awareness:** Immediate visibility into the latest block number and live gas prices (with a +5% buffer applied) to facilitate optimal transaction timing.

### 3. 📡 Sybil Defense Radar
An advanced on-chain identity verification system designed to foster a more trustworthy and secure LitVM community.

-   **Trust Score:** Calculates a dynamic reliability score (up to 100/100) based on transaction history and balance verification.
-   **Elite Trusted Status:** Implements reward tiers for high-reputation users, promoting active and positive participation within the LitVM network.

### 4. 🤖 AI Agentic Optimization Engine
This module permanently records an on-chain footprint via signed self-transfers, marking the wallet as "Agent-Ready" and optimized for LitVM's unique architecture.

-   **Identifier:** `LitSentinel_Optimized_By_Sultan`
-   **Utility:** Enhances wallet readiness and compatibility with advanced LitVM features.

### 5. ❤️ Transparent Ecosystem Charity Module
A built-in philanthropic layer dedicated to supporting the LitVM community fund through transparent, on-chain micro-donations.

> ⚠️ **Development Note:** The current charity address (`0x04733b7D5E8a457B85c2e5178D549BAe2446340a`) is used for **concept testing and demonstration purposes** within the hackathon environment. No official foundation is currently associated with this address.

-   **Beneficiary:** `0x04733b7D5E8a457B85c2e5178D549BAe2446340a`
-   **Micro-Donations:** Supports contributions as low as `0.000001 zkLTC`, making philanthropy accessible to all users.

## 🚀 Getting Started

Follow these instructions to set up LitSentinel locally for development and testing.

### Prerequisites
-   Node.js (v18 or higher recommended)
-   npm, yarn, or pnpm
-   A Web3 wallet (e.g., MetaMask) configured for the LitVM Testnet.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/crypto-sultan228/LitSentinel.git
    cd LitSentinel
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    ```

4.  **Access the application:**
    Open your browser and navigate to `http://localhost:5173` (or the port specified by Vite).
